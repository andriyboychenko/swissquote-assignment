# Crypto Asset Monitoring Policy v1

## wallet-and-exchange-review

Crypto activity should be reviewed for wallet destination, exchange involvement, transaction velocity, and links to failed or reversed fiat activity. Operators should compare wallet address reuse and exchange names with the customer activity timeline.

## operator-notes

When crypto activity contributes to customer risk, the operator note should identify the blockchain, source wallet, destination wallet, transaction hash, and whether the activity is connected to an exchange.
